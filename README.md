## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/ferda-zeynep/my-portfolio.git
```

Navigate to the project:

```bash
cd my-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
